# Independent homepage assets

The frontend does not load the supplied screenshots or screenshot crops. Navigation, footer, payment marks, tool marks, gift cards, and support graphics are HTML/CSS, local icon fonts, or SVG. Existing original site logos are used for branding.

The built-in ImageGen tool generated the following standalone transparent PNG files; optimized WebP copies are used by the frontend.

- `hero-sim-sculpture.png` / `.webp`: Metal SIM cards with gold contacts, lime glass cubes, dark stone pedestal. Prompt requested a clean transparent extraction inspired by the reference sculpture, with all text, buttons, arrows, and other UI removed.
- `controller.png` / `.webp`: Prompt: A premium photorealistic 3D black gaming controller, viewed from front in three-quarter perspective, black analog sticks and D-pad, four small colorful circular buttons on right, subtle lime green reflections on black plastic, matching a polished emerald-and-lime digital services website. Single isolated object, entire controller fully in frame, no pedestal, no text or logos or interface, genuinely transparent background, tight landscape product framing. This is an independent web banner asset, not a screenshot.
- `activation.png` / `.webp`: Prompt: Premium photorealistic 3D product composition: three slightly fanned dark emerald and lavender rectangular software license cards, a silver keyring holding two metal keys and one small brushed silver USB security dongle with a simple square green chip symbol. Subtle lavender and emerald reflections. Single isolated cluster, entire cluster fully in frame, no pedestal, no background, no text or typography or interface. Genuinely transparent background, tight landscape framing. Independent product artwork for a digital services website, never a screenshot.

Payment methods in `PaymentMethods.tsx` use vector elements or local icon fonts: PayPal, Vodafone Cash, InstaPay, USDT, Fawry, and Binance Pay. Every badge links to the existing wallet page. Displaying an icon does not change payment gateway configuration.
